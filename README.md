# Stellar Burgers

Учебный проект React Developer: бургерная с конструктором ингредиентов, авторизацией, оформлением заказов, лентой заказов и историей заказов пользователя.

## Деплой

https://maratshangareev921-creator.github.io/react-burger/

## Стек

- React
- TypeScript
- Redux Toolkit
- React Router
- React DnD
- Vite
- Vitest
- Playwright

## Запуск проекта

```bash
npm install
npm run dev
```

Локальное приложение будет доступно по адресу, который покажет Vite в терминале.

## Проверки

```bash
npm run build
npm test -- --run
npm run e2e
npm run eslint
npm run stylelint
```

Для запуска Playwright-тестов на новой машине может потребоваться установка браузера:

```bash
npx playwright install chromium
```

## Функциональность

- загрузка ингредиентов с API;
- перетаскивание ингредиентов в конструктор;
- расчёт стоимости бургера;
- просмотр деталей ингредиента в модальном окне;
- регистрация, вход, выход и редактирование профиля;
- создание заказа авторизованным пользователем;
- общая лента заказов через WebSocket;
- история заказов пользователя через WebSocket;
- страницы деталей заказа для прямых ссылок и модальных переходов;
- unit-тесты Redux-слайсов;
- Playwright-тесты конструктора с моками API через HAR.
